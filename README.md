# 富谷の洗濯日和

富谷市（気象庁「宮城県東部」）の朝6時〜夕方18時に外干しできるかを ○・△・× で表示するiPhone用ホーム画面アプリ（PWA）。

- ○ 外干しOK：6〜12時・12〜18時の降水確率がどちらも10%以下、予報文に「雨」「雪」なし
- △ にわか雨に注意：降水確率20〜40%、または「にわか雨」「一時雨」などの文言あり
- × 部屋干し：降水確率50%以上、または雨・雪が主な天気

データ：気象庁 https://www.jma.go.jp/bosai/forecast/data/forecast/040000.json （開くたびに取得）

## ホーム画面に追加
GitHub Pagesで公開したURLをSafariで開き、共有 →「ホーム画面に追加」。

## ホーム画面ウィジェット（○△×が自動で変わる）
iPhoneアプリ「Scriptable」（無料）で `widget.js` を使います。
1. App Storeで Scriptable をインストール
2. Scriptableで右上の「＋」→ widget.js の中身を貼り付け → 名前を「洗濯」にして保存
3. ホーム画面を長押し →「＋」→ Scriptable の小サイズを追加
4. 追加したウィジェットを長押し →「ウィジェットを編集」→ Script で「洗濯」を選ぶ
